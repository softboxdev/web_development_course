
## Тематика курсовых проектов

Выберите одну из предложенных тем. Тема определяет технологический акцент и функциональность приложения.

1. Разработка веб‑приложения (SPA) для автоматизации работы компании с применением стороннего API.
2. Разработка веб‑приложения (SPA) для автоматизации работы компании с применением технологии AJAX или подобных.
3. Разработка веб‑приложения (SPA) для автоматизации работы компании с применением framework Tailwind в качестве реализации основного интерфейса.
4. Разработка веб‑приложения (SPA) для автоматизации работы компании с применением framework Bootstrap в качестве реализации основного интерфейса.
5. Разработка веб‑приложения (SPA) для автоматизации работы компании с возможностью регистрации и авторизации в системе с использованием нереляционной БД, а также реализации внутренней панели администрирования приложения.
6. Разработка веб‑приложения (SPA) для автоматизации работы компании с возможностью регистрации и авторизации в системе с использованием реляционной БД, а также реализации внутренней панели администрирования приложения.
7. Разработка веб‑приложения «Интернет‑магазин» с использованием framework Laravel или подобного.
8. Разработка веб‑приложения (SPA) онлайн‑проигрыватель музыки и видеороликов.
9. Разработка веб‑приложения (SPA) построения графиков статистики заказов интернет‑магазина с использованием canvas.
10. Разработка онлайн‑сервиса для организации хранения файлов.
11. Разработка веб‑приложения органайзера.
12. Разработка веб‑приложения для аренды автомобилей с использованием стороннего API для отслеживания местоположения автомобиля.
13. Разработка интернет‑сервиса для размещения частных объявлений.
14. Разработка стримингового веб‑приложения (SPA) с возможностью вести онлайн‑трансляцию.
15. Разработка веб‑сервиса аренды недвижимости.
16. Разработка внутренней CRM‑системы для автоматизации работы компании.
17. Разработка веб‑приложения для оптимизации работы туристической фирмы.
18. Разработка веб‑приложения (SPA) графический редактор для работы с растровой графикой.
19. Разработка RPG‑игры с веб‑интерфейсом.
20. Разработка чат‑бота с веб‑интерфейсом для оптимизации работы компании.
21. Разработка веб‑приложения чат с возможностью общения собеседников в режиме онлайн.
22. Разработка веб‑приложения (SPA) система онлайн‑обучения.
23. Разработка веб‑приложения система отслеживания заказов строительной компании.
24. Разработка веб‑приложения для оптимизации работы Банка.
25. Разработка веб‑приложения (SPA) интернет‑магазин спортивных товаров.
