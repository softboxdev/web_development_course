### Практическая работа № 1. Проектирование базы данных и ER-диаграммы

**Цель:** спроектировать БД для портала «Конференции.РФ» и сохранить ER-диаграмму.

**Оснащение:** СУБД (MySQL), инструмент для ER-диаграмм, офлайн-справочник.

**Ход выполнения:**
1. Изучите предметную область: бронирование помещений (аудитория, коворкинг, кинозал).
2. Выделите сущности: пользователь, помещение, заявка, статус, отзыв.
3. Определите поля и типы данных:
   - пользователь: id, логин (латиница+цифры, ≥6), пароль (≥8), ФИО (кириллица+пробелы), телефон (8(ХХХ)ХХХ-ХХ-ХХ), email;
   - помещение: id, название, тип (аудитория/коворкинг/кинозал);
   - заявка: id, id_пользователя, id_помещения, дата начала, способ оплаты (очное/СБП), статус;
   - статус: id, название («Новая», «Мероприятие назначено», «Завершено»);
   - отзыв: id, id_заявки, текст, дата.
4. Установите связи: пользователь → заявка (1:M), помещение → заявка (1:M), заявка → отзыв (1:1).
5. Постройте ER-диаграмму в СУБД.
6. Сохраните ER-диаграмму в рабочую папку проекта в любом формате.

**Требования к результату:** ER-диаграмма сохранена в проект, таблицы и связи соответствуют функционалу.

**Критерии оценивания (Таблица № 7):**
- Произведение разработки модулей ИС — 6,00
- Разработка подсистем безопасности ИС — 16,00
